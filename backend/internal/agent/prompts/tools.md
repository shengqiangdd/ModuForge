Tool parameters are provided by function-calling definitions — use them. For the full skill catalog (all skills, descriptions, and example invocations), call `skills_doc`.

## Key skills
- read_file / write_file / edit_file / delete_file — file operations
- grep_search / glob_search — search code
- bash — shell commands (build, test, git)
- build_module — compile & package (MANDATORY after writes)
- device_test — install & verify on a connected device
- skills_doc — list all available skills with usage details

MCP-backed tools are namespaced `mcp__<server>__<tool>`.
