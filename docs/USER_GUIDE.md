# ModuForge 用户指南

## 快速开始

### 1. 访问平台
打开浏览器访问: http://192.168.2.9:8086

### 2. 配置AI模型
1. 进入「设置」页面
2. 添加LLM提供商（OpenAI、DeepSeek、Qwen等）
3. 配置API密钥

### 3. 创建项目
1. 点击「新建项目」
2. 输入项目名称和描述
3. 选择项目类型

## 核心功能

### AI代码生成
1. 选择项目
2. 输入代码需求描述
3. 选择AI模型
4. 点击「生成代码」

### 代码修复
1. 选择有问题的代码文件
2. 描述问题
3. 点击「修复代码」

### 多模型协同
1. 选择多个AI模型
2. 输入复杂需求
3. 启用「协同模式」
4. 获得更优结果

访问 API 文档: http://192.168.2.9:8086/api/docs/openapi

## 常见问题

### Q: AI生成的代码质量如何？
A: ModuForge使用多模型协同和质量检查，确保生成的代码符合最佳实践。

### Q: 如何提高生成速度？
A: 启用缓存可以显著提高重复请求的速度。

### Q: 支持哪些编程语言？
A: 目前支持 Go、JavaScript、TypeScript、Python、Java、C++ 等主流语言。
